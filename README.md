# Шифрование папки (Node.js)

Консольная программа для шифрования и дешифрования файлов в папке и всех
вложенных подпапках.

## Как это работает

- Используется алгоритм **AES-256-GCM** через встроенный модуль Node.js
  `crypto` (отдельные библиотеки ставить не нужно).
- Ключ шифрования получается из пароля через функцию `scrypt` - сам пароль
  нигде не сохраняется.
- Каждый файл шифруется отдельно, **прямо на месте**: имя и расширение
  файла не меняются, снаружи файл выглядит так же, как и до шифрования.
- Чтобы программа могла отличить уже зашифрованный файл от обычного, в
  начало зашифрованного файла добавляется небольшая метка (4 байта).
  Именно по ней (а не по имени файла) программа понимает, что файл нужно
  расшифровывать, а не шифровать заново.
- Если при дешифровании ввести неверный пароль, программа не сможет
  расшифровать файл и напишет об ошибке (сам файл при этом не портится).

## Основной класс — Singleton

`CryptoManager` (`src/CryptoManager.js`) реализован как Singleton: получить
его можно только через `CryptoManager.getInstance()`, и во всей программе
это всегда один и тот же объект.

## Защита от опасных папок

Перед тем как начать шифрование или дешифрование, `src/SafetyGuard.js`
проверяет папку и отказывается работать, если это:

- папка самого проекта (иначе программа зашифровала бы сама себя);
- корень целого диска (`C:\`, `/`) - шифровать всё сразу нельзя;
- одна из известных системных папок (`C:\Windows`, `/etc`, `/usr` и т.д.).

Если папка попадает под один из этих пунктов, программа выводит
сообщение и ничего не делает.

## Рекурсивный обход папок

`src/FileWalker.js` - функция `getAllFiles` обходит папку и все вложенные
подпапки рекурсивно (вызывает сама себя для каждой найденной подпапки).

## Запуск

Нужен установленный Node.js.

```
node index.js encrypt <путь_к_папке> [пароль]
node index.js decrypt <путь_к_папке> [пароль]
```

Если пароль не указать, программа спросит его в консоли.

Пример:

```
node index.js encrypt ./my_folder
node index.js decrypt ./my_folder
```

## Примечание

Пароль нигде не сохраняется - если его забыть, расшифровать файлы будет
невозможно.
